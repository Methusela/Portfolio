# Portfolio
Welcome to my personal portfolio website! This project showcases my skills, projects, and experience as a web developer. It is designed to be fully responsive, modern, and easy to navigate.  

## Features
- Responsive design for desktop, tablet, and mobile
- Showcase of personal and professional projects
- About section highlighting skills and experience
- Contact form for easy communication
- Smooth animations and interactive elements

## Technologies Used
- HTML5
- CSS3
- JavaScript
- Bootstrap 5
